Token Radar ranks 198 pre-token protocols by a fitted size curve from the snapshot's own live comparables, with leave-one-out validation and net farm economics for every row.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input path/to/snapshot.json
```
